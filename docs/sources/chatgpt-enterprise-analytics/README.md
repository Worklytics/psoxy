# ChatGPT Enterprise Analytics

**Connector ID:** `chatgpt-enterprise-analytics`

**Availability:** Beta

Replaces [Codex Enterprise Analytics](../codex-enterprise-analytics/README.md) (deprecated): OpenAI
is deprecating the Codex-only `/v1/analytics/codex/workspaces/{WORKSPACE_ID}/usage` endpoint in
favor of this combined ChatGPT+Codex endpoint.

This API allows ChatGPT Enterprise administrators to pull daily ChatGPT and Codex usage metrics for
a workspace. It is intended for dashboarding, reporting, and trend analysis, with metrics
aggregated by day and broken down per-user. Endpoints return time-ordered pages using cursor-based
pagination.

## Data Collected

| Endpoint | Description | Per-user? |
|---|---|---|
| `GET /v1/analytics/workspaces/{WORKSPACE_ID}/usage` | Per-user daily ChatGPT and Codex usage: chats, messages, credits/cost, token counts, per-client and per-model breakdowns, and Codex code attribution (lines of code). | Yes |

`{WORKSPACE_ID}` is your ChatGPT Enterprise workspace id (Worklytics "Workspace Id" / `connector_settings.chat_gpt_enterprise_example_workspace_id`). Query params `start_time` and `end_time` are unix timestamps.

This connector captures the base per-user daily usage row, including the optional
`plugins`/`skills`/`tools` usage expansions (always requested via `include=plugins,skills,tools`).
Workspace-wide grouping and user/group filters are not used, since they are not needed for
per-person aggregate usage reporting.

### Privacy

`user_id` and `actor.user_id`/`actor.email` on the `usage` endpoint are pseudonymized by the
Worklytics DLP Proxy before leaving your network. No message/prompt content is collected by this
connector — only aggregate usage counters.

## Instructions to Connect

1. Add `chatgpt-enterprise-analytics` to `enabled_connectors` in `terraform.tfvars`, then run
   `terraform apply`.
2. Complete source authorization per the `TODO 1 - chatgpt-enterprise-analytics` file:
   1. Open the [OpenAI Admin Console](https://admin.openai.com/credentials?tab=admin-keys) under
      **Credentials → Admin keys → Create new admin key**; choose this workspace, select **Custom**
      permissions, and set **Enterprise analytics API** to **Read**. This is a workspace-scoped
      Admin key, not a Platform API key.
   2. Copy the key into the proxy as the `PSOXY_CHATGPT_ENTERPRISE_ANALYTICS_ACCESS_TOKEN` parameter
      value in your proxy's host platform.
3. Run the proxy health checks in the `TODO 2 - test psoxy-chatgpt-enterprise-analytics` file
   generated by `terraform apply`.
4. Create the **ChatGPT Enterprise Analytics via Psoxy** connection in Worklytics; see the
   `TODO 3 - connect chatgpt-enterprise-analytics in Worklytics.md` file generated by
   `terraform apply`. That file lists the values to enter in Worklytics, including:
   - **Psoxy Base URL** — your deployed proxy/function endpoint URL
   - **Workspace Id** — your ChatGPT workspace id (found in the ChatGPT Admin console at
     https://chatgpt.com/admin, on the workspace settings page)

Worklytics also offers a **direct connection** for this source (no proxy) - the same workspace
Admin key from step 2 is pasted directly into the Worklytics connection settings instead of a
proxy's Secret Manager. See the ChatGPT Enterprise Analytics connector page in Worklytics' own docs
for that setup.
